SNAILED IT! 
SNAILED IT! is a 2D platformer built around the theme "Bounce Back." Play as a little pink hero trying to escape a persistent snail while navigating obstacles, bouncing off shells, and collecting apples that temporarily increase your speed.

The game features:

Fast-paced running and flying mechanics.
Reusable bouncing shells.
Apple collectibles and speed boosts.
A chasing snail enemy.
Multiple difficulty zones and themed environments.
Development Status: Work in Progress

The game is still under development. Most core mechanics and the main menu are implemented, but some features remain unfinished. In particular, the snail-to-player collision and Game Over transition are currently experiencing technical issues that I haven't been able to resolve yet.

This is an ongoing solo game jam project, and further improvements are planned.
